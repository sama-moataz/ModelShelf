# ModelShelf

A curated, zero-cost directory of **open datasets and free APIs for student and indie AI/ML projects**. 30 hand-picked entries across six categories, each with its license, limits, starter code, project ideas and gotchas.

Built static-first with [Astro](https://astro.build), Tailwind CSS 4, [Lucide](https://lucide.dev) icons and `@astrojs/sitemap`: every route is pre-rendered, crawlable HTML.

## Features

- Home page with search, category/type/badge filters and sorting (server-rendered cards, enhanced with a small script)
- 30 detail pages at `/resources/<slug>/` with Google Dataset Search–ready JSON-LD (Dataset, or WebAPI for APIs), a data leakage & preprocessing checklist, an expected baseline benchmark, starter code and a page-specific FAQ (FAQPage JSON-LD)
- Category hub and per-category pages
- Programmatic hubs: `/hardware/{laptop-cpu,free-colab-t4,needs-gpu-subset}/` with tuning guides, and `/access/{no-signup,open-commercial,academic-research}/`
- `/compare/`: one crawlable HTML table of every resource by modality, size, samples, hardware tier, time to baseline and license
- Student-first badges: no signup, no credit card, commercial OK, laptop-friendly, beginner pick, one-line load
- Free-tier estimator for API quotas and dataset size vs. your hardware
- Submit page that opens a pre-filled GitHub issue (no server needed)
- Canonical URLs, Open Graph/Twitter large-image cards (`public/og-image.png`), BreadcrumbList/ItemList/FAQPage JSON-LD, generated `robots.txt`, and `sitemap-index.xml` with `lastmod`
- Vercel Web Analytics (cookie-free) via `@vercel/analytics/astro`

## Develop

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # static output in dist/
npm run preview    # serve the production build
```

## Configuration

The canonical URL lives in `src/config/site.ts` and is wired into `astro.config.mjs` as `site`. Override it with `PUBLIC_SITE_URL`:

```bash
PUBLIC_SITE_URL=https://example.com npm run build
```

`robots.txt` is generated by `src/pages/robots.txt.ts` from the same `SITE_URL`, so its Sitemap line always matches the deployed domain.

## Add a resource

Add an object to `entries` in `src/data/directoryData.ts` (see the `Entry` interface). Besides the basics, every entry needs a `hardware` tier, `samples`, `timeToBaseline`, 2–3 `preprocessingTips` and a `baselineBenchmark`; add `licenseUrl` when the license maps to a Creative Commons or SPDX URL. Pages, hubs, the compare table, sitemap, filters and the estimator pick it up on the next build. Hub definitions live in `src/data/hubs.ts`. Please check the license and free limits against the provider's own page, then update `LAST_CHECKED`.

## Deploy

`vercel.json` is included. Import the repo on Vercel (Astro preset) or any static host; there is nothing to run on a server.

## Notes

Entry URLs were checked on 2026-11-24. Sizes are approximate, and free-tier limits change often, so treat each provider's docs as the source of truth.
