# Resource verification record: 26 November 2026

Every one of the 30 entries was re-checked against its **primary sources** on 26 November 2026: the dataset authors' own page, paper or repository, or the API provider's own pricing, limits and terms pages. Mirrors and re-uploads (Kaggle, a Hugging Face copy, OpenML's licence field) were used only to confirm sizes and loaders, never as the authority on a license.

The result lives in the data, not just in this file. Each entry in `src/data/directoryData.ts` has:

- `verification.status`: `verified` (license, access, size and sample count all matched a primary source) or `partial` (something could not be confirmed).
- `verification.sources`: the primary pages that were read.
- `verification.open`: what is still unconfirmed, required when the status is `partial`.
- `verification.notes`: context a reader needs, such as two official statements that conflict.
- `pricing`: `free-download`, `free-tier` (permanent, within limits), `pay-as-you-go` or `local`, so "free" never hides a card, credits or a limit.
- `baselineSource`: set only when a baseline figure comes from a paper, the authors' page or official docs. Without it, the page labels the baseline a rough guide.

Each resource page shows this in a **Verification** section, and `llms-full.txt` repeats it. `npm test` fails if an entry has no sources, if a partly verified entry does not say what is open, or if a badge contradicts the license or the cost.

## Rules applied

- The hosting site is not the author. When a mirror's license field disagreed with the original source (MNIST's Hugging Face card says MIT; the authors state none), the original source won.
- If the original source states no license, the entry says **"No license specified"** and does not get the Commercial use OK badge.
- Software and models are separate: Ollama's MIT license covers Ollama, not the models it runs.
- Free trial, credits, permanent free tier and local use are labelled differently. Hugging Face Inference Providers turned out to include $0 in monthly credits on Free accounts (PRO, Team and Enterprise get $2 a month), so it is now labelled pay-as-you-go.
- Numbers (sizes, counts, baselines) were kept only when a primary source or a direct measurement supports them. Timings ("~1 min on CPU") are labelled estimates everywhere.

## How the check was done

- Three parallel research passes covered NLP and vision datasets, tabular and audio datasets, and the ten APIs. Each returned verbatim quotes and URLs for every changed field.
- The most consequential claims were then re-read first-hand: Gemini's deprecation and pricing pages, Hugging Face's Inference Providers pricing, Open-Meteo's terms, the Colab FAQ, the IMDB and CIFAR pages, the MNIST archive, the Speech Commands archive URL, Frankfurter's v2 endpoint (a live call) and Ultralytics' YOLO11 table.
- Download sizes come from the provider's listed size or the Hugging Face API's `download_size`, in decimal MB.
- Snippets were checked against current docs and, for keyless APIs, a live request. Python snippets for datasets were not executed (no Python ML stack was available).

## Entries that changed category of claim

- **Commercial use OK removed:** MNIST (no license stated), Oxford-IIIT Pet (conflicting terms), NASA APOD (many images are copyrighted).
- **No longer free on a free account:** Hugging Face Inference Providers ($0 monthly credits on Free accounts; purchased pay-as-you-go credits or a PRO, Team or Enterprise plan needed). It stays listed with a "Paid credits" label and a warning, by the maintainer's decision of 26 November 2026, even though it no longer meets the "free without a credit card" inclusion rule.
- **Snippets that would have failed:** Speech Commands (loader script removed in datasets 4.0), Gemini (deprecated model), Groq (picked an arbitrary model, possibly a speech model).

## Consistency pass: 27 November 2026

A cross-page audit compared every fact that appears on more than one page (cards, resource pages, hubs, landing pages, category guides, combos, compare, the estimator, FAQs, JSON-LD and the llms files). No primary source was re-read for this pass, so `LAST_CHECKED` stays 26 November 2026. What changed:

- **Badges derived from fields:** `no-signup`, `no-card` and `laptop-friendly` are now computed from `access`, `pricing` and `hardware`. Before, SQuAD 2.0, CIFAR-10 and ESC-50 showed "Laptop-friendly" while rated for a free Colab T4, and the ten APIs (rated Laptop CPU) did not, so the homepage filter and the Laptop CPU hub disagreed (13 vs 20 results).
- **Copy that had drifted from the data:** MNIST was quoted as ~15 MB (data: 18 MB), the Free Spoken Digit Dataset as ~20 MB (16 MB), Frankfurter as "daily European Central Bank" rates (v2 draws on central banks and official sources, including the ECB), Open-Meteo as "about 80 years" of history (back to 1940), and the audio guide said all larger audio datasets fit a free Colab T4 (LJ Speech is rated GPU or subset). These figures are now read from the entries.
- **CIFAR-10:** time to baseline now quoted on a T4, matching its hardware tier; the beginner path no longer says every pick trains on a laptop CPU.
- **LibriSpeech:** its size is labelled "dev-clean subset" wherever it appears (new `sizeNote` field).
- **"Free" wording:** the LLM category is renamed "LLM & model APIs" because it lists one pay-as-you-go provider; whole-site descriptions say "open datasets and APIs" rather than "free APIs"; the DataCatalog JSON-LD says "10 APIs (9 free to call)"; the Laptop CPU hub no longer says "no cloud bill".
- **New checks in `npm test` and `npm run test:dist`** catch these classes of drift: derived badges vs fields, pricing vs access, paid entries described as free, license wording vs license URL, combo hardware and license notes, sizes and counts quoted in copy, stale llms files, facts on each resource page vs the data, FAQ and breadcrumb JSON-LD vs visible text, and `isAccessibleForFree` vs pricing.

## Re-checking later

1. Re-read the sources listed for the entry and compare every field.
2. Update the entry, set `verification.checked` to the date, and move items between `open` and resolved as appropriate.
3. After a full pass over all entries, update `LAST_CHECKED`.
4. Run `npm test`, then `npm run build && npm run test:dist`.

Things known to change soon: the NASA APOD repository moves on 1 December 2026, Gemini model names change often, and OpenRouter's list of free models changes daily.
